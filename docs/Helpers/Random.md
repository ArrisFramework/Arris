## Методы

### `weighted()`

Взвешенный случайный выбор ключа из массива: ключи — возвращаемые значения,
значения — их веса. Чем больше вес, тем выше вероятность.

```php
public static function weighted(
    array $weights,
    mixed $fallback = null
): mixed
```

| Параметр    | Тип                                 | По умолчанию | Описание                                                        |
|-------------|-------------------------------------|--------------|-----------------------------------------------------------------|
| `$weights`  | `array<int\|string, int\|float>`    | —            | Веса: ключ => вес. Вес должен быть конечным и неотрицательным    |
| `$fallback` | `mixed`                             | `null`       | Что вернуть, если сумма весов равна нулю                        |

**Возвращает:** ключ массива (`int` или `string`) либо `$fallback`, если сумма весов `<= 0`.

**Примеры:**

```php
use Arris\Helpers\Random;

// 'b' выпадет примерно в 75% случаев
Random::weighted(['a' => 1, 'b' => 3]);

// Нулевой вес не выпадает никогда
Random::weighted(['a' => 0, 'b' => 1, 'c' => 0]); // всегда 'b'

// Все веса нулевые — возвращается fallback
Random::weighted(['a' => 0, 'b' => 0], 'none');   // 'none'

// Дробные веса поддерживаются
Random::weighted(['low' => 0.5, 'high' => 2.5]);

// Ключи сохраняются как есть
Random::weighted([1 => 1, 'one' => 1]);           // 1 или 'one'
```

Алгоритм: `roll = mt_rand() / (mt_getrandmax() + 1) * total`, затем
последовательное вычитание весов до первого отрицательного остатка.
Такая формула корректно работает и с целыми, и с дробными весами, и не
выходит за верхнюю границу, когда `mt_rand()` возвращает максимум.

## Ошибки и краевые случаи

| Ситуация                            | Поведение                        |
|-------------------------------------|----------------------------------|
| Пустой массив `[]`                  | `InvalidArgumentException`       |
| Вес — не `int` и не `float`         | `InvalidArgumentException`       |
| Вес `INF`, `-INF` или `NAN`         | `InvalidArgumentException`       |
| Отрицательный вес                   | `InvalidArgumentException`       |
| Сумма весов `0` (все нули)          | возвращается `$fallback`         |
| `PHP_INT_MAX` и больше              | сумма считается как `float`, работает |

Веса-строки (`'1'`), `bool`, `null`, массивы и объекты намеренно **не**
приводятся к числу — это ошибка вызывающего кода, а не повод для тихого
преобразования.
